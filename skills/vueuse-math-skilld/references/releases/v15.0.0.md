# v15.0.0

### &nbsp;&nbsp;&nbsp; Breaking Changes

- Drop templateRef &nbsp;-&nbsp; by @43081j and @ilyaliao in https://github.com/vueuse/vueuse/issues/4883 <samp>(5cc18)</samp>
- Drop support for Node.js 20 &nbsp;-&nbsp; by @antfubot in https://github.com/vueuse/vueuse/issues/5553 <samp>(1ad39)</samp>
- **core**: Remove deprecated timer options in favor of `scheduler` &nbsp;-&nbsp; by @OrbisK in https://github.com/vueuse/vueuse/issues/5564 <samp>(c02ab)</samp>
- **useEventSource**: Handle SSE 'message' type and trigger both onmessage and addEventListener &nbsp;-&nbsp; by @ixyzorg, @OrbisK and **Anthony Fu** in https://github.com/vueuse/vueuse/issues/5331 <samp>(77b57)</samp>
- **useIDBKeyval**: Sync changes across tabs &nbsp;-&nbsp; by @Slessi in https://github.com/vueuse/vueuse/issues/5338 <samp>(ee4ec)</samp>
- **useThrottleFn**: Change default `trailing` option from false to true &nbsp;-&nbsp; by @kyumoon and @OrbisK in https://github.com/vueuse/vueuse/issues/5249 <samp>(e9fe3)</samp>

##### &nbsp;&nbsp;&nbsp;&nbsp;View changes on GitHub

Notes for `@vueuse/math`: this release contains no `@vueuse/math` API changes. The package gains the Node.js `>=22` engines requirement (`package.json` `engines.node`) and pins `@vueuse/shared@15.0.0`; the export surface is identical to v14.
